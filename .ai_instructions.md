# AI Instructions for this Project

## Interaction Preferences
- **Answer Questions First**: When the user asks a question (even if combined with a conditional command), always provide the answer first before performing any actions.
- **Confirmation for Actions**: After answering a question that was tied to a conditional task, wait for a brief acknowledgement or clearly state that the action is now being performed if the user's intent was "answer and then do it".

## Project Context
- This project is `syn-grammar`, a parser generator for Rust.
- Built-ins and their return types are critical for documentation accuracy.
